HealthData@EU Central Platform — Release 7 Shipped, Release 8 Due September 2026
Following the open-source launch (Release 6, January 2026), DG SANTE has shipped Release 7 (May 2026) of the HealthData@EU Central Platform on code.europa.eu, with Release 8 scheduled for September 2026 — an ongoing cadence of reusable, open-source building blocks Member States can use to connect national catalogues, access points and HDABs to the EU-level EHDS secondary-use infrastructure.

TEHDAS2 Publishes Practical Guideline on Using Data in a Secure Processing Environment
New — first in a planned series of practical implementation tools for the EHDS Regulation, this TEHDAS2 guideline walks researchers and data users through how to work inside an accredited SPE (identity/access management, audit logging, output vetting), complementing national efforts such as Germany's DACO and Finland's/Spain's SPE deployments referenced in prior digests.
📅 2026 · tehdas.eu
