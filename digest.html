News & Tools

TEHDAS2 Publishes Technical Specifications for Secure Processing Environments
New technical specification (published 11 June 2026) defines the minimum technical, functional and security capabilities Health Data Access Bodies must build into their SPEs, and explicitly allows SPEs to be offered as an external service to an HDAB — directly relevant to any Kubernetes/cloud-native SPE procurement decision.
📅 11 June 2026 · tehdas.eu · Full spec on Zenodo
MinimumViableHealthDataspacev2 — Data Permit Now Gates the SPE (Art. 61(1), 73)
Community open-source project modelling a full EHDS secondary-use flow (drug-repurposing study on synthetic hospital data, HDAB-governed access) merged a change so the data permit gates entry to the Secure Processing Environment — a concrete, runnable reference for the permit → SPE handoff. Independent project, not EC-affiliated.
📅 18 September 2026 (2 days ago) · GitHub — ma3u/MinimumViableHealthDataspacev2
open-daams — Open-Source Reference Implementation of the EHDS Data Access Application Management System
New independent GitHub project implementing the DAAMS workflow based on TEHDAS2 deliverable D6.4. Useful as a starting point/reference for HDAB tooling, though SPE integration itself is not yet implemented in the project. Not affiliated with the European Commission, TEHDAS2 or HealthData@EU.
📅 2026 · GitHub — mdevalk/open-daams · related community effort: openEHDS
